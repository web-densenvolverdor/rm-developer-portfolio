# RM Developer — Portfólio

## Como abrir
1. Extraia a pasta `rm-developer`.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server).

## Estrutura
- `index.html`: conteúdo e estrutura.
- `css/style.css`: identidade visual, layout, responsividade e animações.
- `js/script.js`: menu mobile, animações de entrada, navegação ativa e barra de progresso.
- `img/`: pasta reservada para imagens próprias dos projetos.

## Antes de publicar
- Confira o link do LinkedIn na seção Contato e substitua pelo endereço direto do seu perfil.
- Confira os links de demonstração dos projetos. Só o link do primeiro site foi incluído porque é o endereço confirmado.
- Adicione links do GitHub ou demonstrações dos outros projetos quando estiverem publicados.
- Revise telefone e demais dados de contato antes de divulgar.

O portfólio usa fontes do Google Fonts; sem internet, o navegador usará fontes alternativas.
